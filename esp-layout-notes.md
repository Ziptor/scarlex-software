# ESP Layout Editor

## Использование

Откройте меню Insert → ESP → Layout Editor. В превью находится бокс 100×200, манекен, сетка и оси. Перетаскиваются Role, Weapon, Distance и Name. Оружие использует текущий режим Text / Icon / Both и общий размер иконки. У скрытого элемента остаётся полупрозрачная область редактирования; включить его можно галочкой под превью.

Выбор Element и числовые Offset X / Offset Y позволяют точно подстроить выбранный элемент. Reset layout возвращает исходные положения и видимость. Если нижние настройки не видны, прокрутите правую панель. Начальная высота меню увеличена, чтобы превью помещалось целиком на обычном экране; размер окна по-прежнему можно менять.

## Координаты

- X — смещение в пикселях от центра бокса, Y — от его верхней границы на эталонном боксе 100×200.
- По умолчанию Role находится в `(0,205)`, то есть на 5 px ниже нижней грани; Weapon — `(0,225)`, Distance — `(0,-20)`.
- При включённом Scale positions with box положения внутри бокса масштабируются вместе с ним. Отступы снаружи бокса остаются в пикселях: надпись выше верхней грани на 20 px сохраняет этот отступ и для далёкого игрока. Это предотвращает слипание подписей с постоянным размером шрифта.
- При выключенном масштабировании X/Y применяются буквально от центра по X и верха по Y.
- При перетаскивании весь блок ограничивается областью превью; дополнительно действуют пределы X −200…200, Y −200…400. Блок оружия учитывает высоту иконки, названия и метаданных.

Функция `game_entities::esp_layout_position` из `EspLayout.h` используется и редактором, и настоящим ESP. Скрытие роли не сдвигает оружие: у каждого элемента независимая позиция.

## Конфигурация

Используется существующий профиль `%LOCALAPPDATA%\RobRunTool\menu_settings.json`. В него добавляется корневая секция `esp_layout`. Дополнительный config.json программа не создаёт. Старые профили без этой секции получают начальную раскладку автоматически.

Изменения редактора сохраняются атомарно после отпускания мыши и завершения активного редактирования, а не на каждом движении. Сохранение раскладки работает и при выключенном общем autosave. При закрытии меню или программы незавершённое изменение также фиксируется. Неудачное сохранение показывается в статусе меню.

`esp-layout.example.json` — пример секции. При ручном переносе добавьте `esp_layout` в существующий профиль, сохранив остальные настройки. Замена всего профиля минимальным примером сбросит отсутствующие настройки на значения по умолчанию.

## Name

Добавлены раскладка Name и необязательное поле `Entity.name`. Имя рисуется, если оно заполнено и элемент видим. Текущий reader имя игрока не получает, поэтому в игре эта подпись пока отсутствует; текст Player name существует только в превью. Позиция и видимость уже сохраняются для будущего источника имён.

## Файлы и проверка

Обновлены `game_entities.h`, `ESPModule.h/.cpp`, `menu_module.h/.cpp`, `src/app.cpp`; добавлены `EspLayout.h` и `EspLayoutEditor.inl`. Оба новых файла должны находиться в корне проекта рядом с menu_module.cpp. Структура `src/app.cpp` в архиве сохранена.

MSVC C++20 Release x64 собран. Проверки: 34 сценария взаимодействия/конфигурации/рендера редактора, 652 проверки существующей логики и применения раскладки с учётом границ тестовых данных, 58 проверок иконок/режимов/конфигурации. Проверены отсутствие скачка при захвате, несколько последовательных движений мыши, ограничение рамками превью, отсутствие записи во время движения, запись после отпускания при отключённом autosave, сохранение/загрузка, независимость элементов и отсутствие перемещения меню. Кадр редактора считан с D3D11 и визуально проверен. Проверка нового редактора непосредственно в реальном матче ещё не выполнена.

## Запуск

Закройте старый оверлей, затем:

```powershell
cd 'C:\Users\lucky\Documents\opencode1\build\vs2022-x64\Debug'
& 'C:\Users\lucky\Documents\opencode1\build\vs2026-scarlex-layout-editor-x64\Release\rob_run_tool.exe'
```

В меню перетащите Role и Weapon, отпустите мышь и закройте меню. В игре подписи должны следовать выбранной раскладке. Повторный запуск должен восстановить положения.
